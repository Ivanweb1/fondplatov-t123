Как вставлять

  1. Создать страницу в Tilda и задать ей адрес из таблицы — без слэша на конце.
  2. Добавить блок T123 (Другое → HTML-код).
  3. Нажать «Скопировать» и вставить код целиком.
  4. Опубликовать.

Если на сайте включено глобальное меню Tilda, на этих страницах его нужно отключить — иначе оно продублирует нашу шапку.

После публикации

  • Шапка чёрная во всю ширину, логотип на месте.
  • Тёмный фон и антиквенные заголовки — значит стили с GitHub подтянулись.
  • Бургер-меню на мобильном открывается.
  • Ссылки ведут на адреса вида /about, а не на github.io. Пока страница не создана, ссылка даст 404 — это нормально.
  • PDF документов открываются.

Редиректы

Настройки сайта → SEO → Редиректы страниц (Code 301).

/ustav/documents#ustav
/certificate/documents#certificate
/egrul/documents#egrul
/fondcard/documents#fondcard
/oferta/documents#oferta
/otc/documents#reports

Сначала снять старые страницы с публикации: Tilda применяет 301 только к несуществующим адресам.

Файлы в Tilda загружать не нужно — стили, логотип, документы, слайды и видеофон остаются на GitHub Pages и подтягиваются по абсолютным адресам. Обратная сторона: сайт зависит от репозитория Ivanweb1/fondplatov-t123.

Страницы собраны скриптом scripts/build-tilda.py. Если адрес страницы меняется — правится таблица в скрипте, и всё перегенерируется заново.
