# Фонд имени М. И. Платова — Tilda T123

Первые два экрана обновлённой главной страницы фонда:

- тёмный презентационный hero-экран;
- текущий сбор и анимированная лента пожертвований;
- статистика фонда;
- карточка проекта «Вихорь-атаман Матвей Платов»;
- адаптивная версия для мобильных устройств.

## Установка в Tilda

1. Откройте файл `t123-two-screens.html`.
2. Скопируйте его содержимое целиком.
3. В Tilda добавьте блок **Другое → T123 «HTML-код»**.
4. Вставьте код, сохраните изменения и опубликуйте страницу.

## Локальный просмотр

Откройте `preview.html` в браузере или запустите:

```powershell
node serve.cjs
```

После этого страница будет доступна по адресу `http://127.0.0.1:8765/`.
